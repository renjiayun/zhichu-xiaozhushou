# 智厨小助手 · AI 食材菜谱生成器

《人工智能基础与应用》课程大作业 · **AI + 食品** 方向
单页静态网页（HTML + CSS + 原生 JavaScript），无需后端、无需安装依赖。

> 输入冰箱里现有的食材和忌口，生成 3 套可直接下厨的菜谱：用料（标注需补充）、四步做法、每人份热量与蛋白质估算、忌口规避说明。

## 三、功能介绍

| 功能 | 说明 |
| --- | --- |
| 食材输入 | 文本框输入 + 10 个常用食材标签，点击即可增删并自动同步 |
| 忌口过滤 | 支持「不吃辣」「海鲜过敏」等口语描述，命中即从候选池剔除，并给出被排除数量 |
| 口味 / 时长 / 低卡 | 口味四档（不限、清淡、酸辣、重口）、时长三档（15 / 30 分钟 / 不限）、低卡优先加权 |
| 用餐人数 | 1～8 人，热量与蛋白质按人数换算 |
| 菜谱卡片 | 菜名、匹配度、口味/耗时/难度、用料（区分已有与需补充）、四步做法、营养估算、小贴士 |
| 换一批 | 在候选中翻页，最多给出 3 套一组的备选方案 |
| 复制 | 复制单道菜谱或整桌菜单为纯文本（clipboard API + textarea 兜底） |
| 收藏 | 写入 localStorage，刷新后仍保留 |
| 空状态与兜底 | 未生成时显示引导页；条件过严时提示放宽口味或时长，而不是硬凑菜谱 |
| 响应式 | 900px / 560px 两个断点，桌面两栏、手机单栏 |

## 五、实现说明

1. **菜谱知识库**：内置 21 道家常菜的结构化记录（菜名、口味标签、耗时、难度、每人份热量/蛋白质/脂肪、用料与用量、基础调料、四步做法、小贴士），以 JavaScript 常量写在页面里。
2. **匹配打分**：`命中率 = 已有食材命中的用料数 / 用料总数`，再叠加修正项——每样需补充的用料 −9 分、超时 −20 分、时长命中 +4 分、低卡命中 +12 分 / 未命中 −8 分，最终按得分降序取前 3（满分 100）。
3. **忌口过滤**：先把口语去掉「不吃 / 过敏 / 忌」等动词，再用同义词映射表扩展词族（辣 → 辣/豆瓣/花椒/小米辣，海鲜 → 虾/蟹/贝，鸡蛋 → 蛋……），对「菜名 + 用料 + 调料」做子串匹配，命中即剔除并计数。
4. **营养估算**：以每人份常量为基础，乘以用餐人数得到全桌热量与蛋白质合计，页面已标注「估算值」口径。
5. **状态与持久化**：单个 `state` 对象管理人数、口味、时长、低卡开关与分页游标；收藏写入 `localStorage`；复制优先 `navigator.clipboard`，在 `file://` 等非安全上下文自动降级为隐藏 textarea + `execCommand`。

> 说明：本版本的「AI 生成」由页面内的规则引擎模拟，目的是保证作品在无网络、无 API Key 的环境下仍可运行、结果可复现、每次输出可解释。

## 六、如何接入真实大模型（可选扩展）

1. 在 `generate()` 中把「打分取前 3」替换为一次带约束的模型调用，提示词模板如下：

```
你是家常菜菜谱助手。请只输出 JSON 数组，不要多余文字。
约束：现有食材【{ingredients}】；忌口【{avoids}】；口味【{taste}】；人数【{people}】；30 分钟内可完成。
字段：name, tastes, minutes, difficulty, kcal, protein, fat, ingredients[{name, amount}], pantry, steps[4 条], tip。
要求：不使用忌口食材；步骤含关键动作与时间；热量按每人份估算。
```

2. 校验返回的 JSON 结构（字段齐全、`ingredients` 为数组），异常时回退到本地菜谱库，避免接口异常导致页面空白；
3. 渲染函数 `render()` 与卡片结构可直接复用，无需改动。

## 七、已知限制

- 菜谱库为 21 道常见家常菜，覆盖范围有限，遇到少见食材只能给出「需补充主料」的提示；
- 热量与蛋白质为按常见分量的估算值，不区分煎炸与蒸煮的差异，不能替代营养学计算；
- 暂不支持拍照识别食材，仍需手动输入；
- 口味、时长、忌口叠加过严时，可能出现无合适菜谱的情况（此时页面会给出放宽条件的提示）。
